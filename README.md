
EniForum :
      Plateforme pour faciliter l'organisation du Forum d'Entreprise ENICarthage.  
Technologies : Spring Boot | Angular | MySQL | Module IA (analyse CVs)

## Objectifs
- Gérer le projet Forum annuel
- Suivi des tâches et comités
- Gestion workshops et conférences
- Analyse et suggestion CVs via IA

## Rôles principaux
- **Admin** : supervision globale, création du projet Forum
- **Comité Pilotage** : suivi des comités, validation CVs
- **Coordinatrice** : suivi des tâches et workshops
- **Chef de comité** : gestion membres et tâches internes
- **Membre de comité** : suivi et mise à jour des tâches
